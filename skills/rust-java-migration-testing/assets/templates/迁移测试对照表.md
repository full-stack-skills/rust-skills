## 四、整体迁移验收模块

任何仓库/产品级迁移完成结论都必须由一个 `<project>-test` workspace package
统一拥有完整回放和差分结果；多 crate、语言绑定/适配器或源系统套件尤其
不能省略。生产 crate 内部测试只作为局部证据。

> `<project>-test` 的最终目录名与 Cargo package 名保持一致；父目录必须引用迁移路线图的 workspace 拓扑决策。小型根目录扁平项目通常为 `<project>-test/`，大型收纳项目可为 `crates/<project>-test/` 或真实测试家族下的同名目录。
